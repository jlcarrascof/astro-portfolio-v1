Aplicación colaborativa de gestión de proyectos con tablero Kanban estilo Trello.

### Funcionalidades clave
- Tablero Kanban con **drag & drop**
- Notificaciones en tiempo real via **WebSockets**
- Roles de usuario: admin, manager, member
- Reportes de productividad
- Comentarios y actividades en tiempo real

### Stack técnico
- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, Socket.io
- **Base de datos:** MongoDB con Mongoose
