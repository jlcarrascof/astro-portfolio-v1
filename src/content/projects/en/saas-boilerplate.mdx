Complete SaaS starter kit with multi-tenant architecture.

### Key Features
- **Multi-tenancy** with data isolation per client
- Role-based authentication: admin, owner, member
- Recurring billing with **Stripe**
- Admin dashboard with metrics
- **Swagger**-documented REST API
- **GitHub Actions** CI/CD pipeline
- **Docker Compose** deployment

### Tech Stack
- **Frontend:** Vue 3, TypeScript, Pinia
- **Backend:** NestJS, PostgreSQL, Prisma
- **Infrastructure:** Docker, AWS, GitHub Actions
