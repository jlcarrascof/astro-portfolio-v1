Built a complete e-commerce platform with **Vue 3** on the frontend and **NestJS** on the backend.

### Key Features
- Product catalog with search and filters
- Persistent shopping cart
- Payment processing with **Stripe**
- Real-time admin dashboard with charts
- JWT authentication with roles (admin, customer)
- Automated deployment with **Docker** and **AWS ECS**
- Email notifications

### Tech Stack
- **Frontend:** Vue 3, TypeScript, Tailwind CSS
- **Backend:** NestJS, PostgreSQL, TypeORM
- **Infrastructure:** Docker, AWS ECS, GitHub Actions
