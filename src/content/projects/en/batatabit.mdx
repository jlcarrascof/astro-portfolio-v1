### 📌 Project Description
**Batatabit** is a cryptocurrency exchange and price tracking landing page designed following the **Mobile-First** paradigm. The project focuses on presenting real-time exchange rates and commission fees with a clean, accessible, and fully responsive user interface.

### 🛠️ Key Technical Challenges Resolved
- **Mobile-First Architecture:** Designed initially for smartphone viewports (320px) and progressively enhanced for desktop devices using `@media (min-width: 930px)`.
- **Fluid Layouts:** Refactored rigid containers into fluid schemes (`max-width: 930px; width: 100%`), eliminating horizontal overflow.
- **Optimized Pricing Slider:** Touch-friendly horizontal slider on mobile without invasive native scrollbars (`scrollbar-width: none`), transitioning to a centered 3-column flex grid on desktop views.
- **Typography Normalization:** Fixed line-height CSS bugs (`line-height: 1.5rem`) and auto-fitting date badge containers (`width: max-content`) to eliminate text clipping.

### 🚀 Stack & Tooling
- **Markup:** Semantic HTML5
- **Styling:** Native CSS3 (CSS Variables, Flexbox, Media Queries)
- **Methodology:** Mobile-First Responsive Web Design
