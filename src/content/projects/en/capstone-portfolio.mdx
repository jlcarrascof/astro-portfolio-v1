### 📌 Project Description
**Capstone Level 1 Portfolio** is a personal developer brand website designed to showcase frontend software projects, technical skills, and provide a direct contact channel via a real-time validated form.

### 🛠️ Key Technical Challenges Resolved
- **WCAG 2.1 AA Accessibility:** Added descriptive `alt` tags across image assets, `aria-label` attributes on social navigation links, and enhanced color contrast ratios above 4.5:1.
- **Fluid & DOM-Compliant Layout:** Replaced rigid grid rows with a dynamic Flexbox container featuring accessible alternating card layouts (`:nth-child(even)`), preserving screen reader DOM order.
- **Fluid Project Details Modal:** Redesigned interactive popup modal with native **`ESC`** key press dismissal and ambient backdrop click listening.
- **Real-Time Form Validation:** Bound `input` event listeners to automatically clear validation error banners as soon as the user corrects their email syntax.
- **Code Quality Compliance:** Full refactoring passing clean tests with **0 errors in Stylelint and 0 errors in ESLint**.

### 🚀 Stack & Tooling
- **Markup:** Semantic HTML5
- **Styling:** Native CSS3 (Flexbox, Media Queries, Transitions)
- **Logic:** JavaScript ES6+ (DOM Manipulation, Event Listeners)
- **Quality:** Stylelint & ESLint Compliance
