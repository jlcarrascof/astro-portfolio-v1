### 📌 Project Description
**Roland Garros Tournament (Capstone Solo Level 1)** is a promotional web application designed to present tournament stages, historical milestones, and player profiles for top-ranked international tennis stars.

### 🛠️ Key Technical Challenges Resolved
- **WCAG 2.1 AA Accessibility:** Integrated `aria-label`, `role="button"`, and keyboard navigation across menus and social links. Reordered semantic heading hierarchy (`<h1>` -> `<h2>`) avoiding unranked jumps.
- **60fps GPU Mobile Navigation:** Replaced heavy CPU `margin-left` animations with GPU hardware-accelerated transforms (`transform: translateX()`), delivering smooth 60fps mobile drawer transitions with auto-close on link clicks and `ESC` key press dismissal.
- **Strict HTML5 Syntax:** Wrapped partner list elements in valid `<ul>` containers and consolidated duplicate DOM images for a lightweight payload.
- **Clean Dynamic DOM Rendering:** Eliminated 404 network asset errors using native DOM element creation for player profile cards.
- **Network Performance:** Added `<link rel="preconnect">` tags to optimize DNS resolution and TLS handshakes for font CDNs.

### 🚀 Stack & Tooling
- **Markup:** Semantic HTML5
- **Styling:** Native CSS3 (GPU Acceleration, Flexbox, Media Queries)
- **Logic:** JavaScript ES6+ (DOM Manipulation, Event Listeners)
- **Quality:** Stylelint & ESLint Compliance
