Desarrollé una plataforma de e-commerce completa con **Vue 3** en el frontend y **NestJS** en el backend.

### Funcionalidades clave
- Catálogo de productos con búsqueda y filtros
- Carrito de compras con persistencia
- Pasarela de pago integrada con **Stripe**
- Panel administrativo con gráficos en tiempo real
- Autenticación JWT con roles (admin, cliente)
- Despliegue automatizado con **Docker** y **AWS ECS**
- Notificaciones por correo electrónico

### Stack técnico
- **Frontend:** Vue 3, TypeScript, Tailwind CSS
- **Backend:** NestJS, PostgreSQL, TypeORM
- **Infraestructura:** Docker, AWS ECS, GitHub Actions
