Boilerplate completo para startups SaaS con arquitectura multi-tenant.

### Funcionalidades clave
- **Multi-tenancy** con aislamiento de datos por cliente
- Autenticación con roles: admin, owner, member
- Facturación recurrente integrada con **Stripe**
- Panel de administración con métricas
- API REST documentada con **Swagger**
- CI/CD con **GitHub Actions**
- Despliegue con **Docker Compose**

### Stack técnico
- **Frontend:** Vue 3, TypeScript, Pinia
- **Backend:** NestJS, PostgreSQL, Prisma
- **Infraestructura:** Docker, AWS, GitHub Actions
