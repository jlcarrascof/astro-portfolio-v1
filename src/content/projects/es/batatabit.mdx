### 📌 Descripción del Proyecto
**Batatabit** es una landing page de intercambio y monitoreo de criptomonedas diseñada bajo el estándar **Mobile-First**. El proyecto se enfoca en visibilizar las tasas de cambio de divisas y comisiones en tiempo real con una interfaz limpia, accesible y totalmente adaptativa.

### 🛠️ Desafíos Técnicos Resueltos
- **Arquitectura Mobile-First:** Diseñado inicialmente para pantallas de smartphones (320px) e incrementado paulatinamente mediante `@media (min-width: 930px)` para dispositivos de escritorio.
- **Layouts Fluidos:** Refactorización de contenedores rígidos hacia esquemas fluidos (`max-width: 930px; width: 100%`) evitando desbordamientos horizontales.
- **Slider de Planes Optimizado:** Slider táctil horizontal en móviles sin barras de scroll nativas toscas (`scrollbar-width: none`), transformándose en una grilla flex de 3 columnas centradas en escritorio.
- **Normalización Tipográfica:** Corrección de estilos de interlineado (`line-height`) y cajas adaptables (`width: max-content`) para Insignias de fecha de actualización.

### 🚀 Stack & Herramientas
- **Lenguaje:** HTML5 Semántico
- **Estilos:** CSS3 Nativo (Variables CSS, Flexbox, Media Queries)
- **Metodología:** Mobile-First Responsive Web Design
